# AimDial

用自适应的静态点击测试，在你的当前灵敏度附近找出真正适合你的那个值。

瓦罗兰特的灵敏度本质是"鼠标移动多少距离，视角转多少度"。AimDial 让你在若干个候选灵敏度下各打一局六目标式静态点击，然后按成绩用**黄金分割搜索**收窄区间，通常在 6–10 轮内收敛到一个 ±5% 的推荐值。

## 本地运行

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # 纯函数单测（换算 / 搜索 / 计分 / 命中判定）
npm run build    # 产物输出到 dist/
npm run preview  # 预览生产构建
```

Node >= 18。

## 使用流程

1. 填鼠标 **DPI**。游戏内灵敏度可留空——留空时按 `256 eDPI` 档位换算（1600×0.16、800×0.32、400×0.64 等价）。
2. 点击"开始校准"。每一轮会给出一个候选灵敏度，点击画面后鼠标被锁定。
3. 测试采用类 Sixshot 的静态点击规则：**场上始终有 6 个固定大小的小目标**，打掉一个立刻在别处补一个，60 秒内尽可能多地击杀。
4. 每轮结束后记录成绩，搜索区间按黄金分割收缩；区间宽度降到 10% 或达到 14 轮上限时结束。
5. 结果页给出推荐灵敏度、eDPI、cm/360°，历史记录存在浏览器 `localStorage`。

按 `Esc` 暂停（计时同时暂停），点击画面继续。

目标半径约为画面短边的 0.78%（限制在 3–12px，1080p 下约 17px 直径），**不随距离变化**——这是 Sixshot 的关键设计，让测试衡量的是指针精度而非"远近大小权衡"。

六个目标始终锚定在正前方的一面墙上（水平 ±25°、垂直 ±19°，大约占画面中间三分之一），打掉一个就在同一面墙的别处补一个，**永远不需要转身**，只需要甩枪。分布范围是照着 Sixshot 录屏逐帧统计出来的：六颗球的包围盒平均只占画面宽度的 26%、高度的 39%。

场地按 Sixshot 的实机画面还原：浅灰的封闭房间，天花板偏暗、墙面中性灰、地面最亮，墙与地面铺满细密方格作为尺度参照——亮面和纹理才让墙显得远。画面只有分数、剩余时间条和命中率三个读数。

投影用 **70° 垂直 FOV**（Aim Lab 的默认值，16:9 下约等于水平 103°）加标准小孔投影，和游戏里左右甩枪时的透视收缩一致。之前用的 75° 偏广，画面边缘的横向拉伸是 2.86 倍，现在是 2.55 倍。

鼠标位移与瓦罗兰特 **1:1**（`0.07°/count × 灵敏度`），并请求未经系统加速的原始输入。指针锁定按 CSS 像素上报位移，而 Windows 显示缩放（如 150%）会把原始计数除掉，所以还要乘回 `devicePixelRatio`，否则手感会偏慢。

## 计分

```
accuracy = 命中 / 射击
ttk      = 总时长 / 命中数
score    = accuracy² × 100 / max(ttk, 0.15)
```

准度做平方，因此漏枪的惩罚重于单纯变慢；TTK 设下限，避免一次"蒙中"得到无穷大分数。

## 搜索算法

- 初始区间：当前 eDPI 的 **±40%**
- 每步在区间内取两个黄金分割点，分别测一局，落败一侧被丢弃，区间按 0.618 收缩
- 终止：`(hi - lo) / centre <= 10%`，或满 14 轮
- 若最优值贴着搜索区间的外边界收敛，结果页会提示"真实最佳可能更极端"，并建议以该值为新基准再跑一次

## 部署到 Vercel

这是一个纯静态的 Vite 单页应用，无需服务端、无需环境变量。

### 方式一：Git 仓库导入（推荐）

1. 把项目推到 GitHub / GitLab。
2. 在 Vercel 打开 **Add New → Project**，导入该仓库。
3. 框架预设选 **Vite**（`vercel.json` 已写明 `buildCommand` / `outputDirectory`，通常无需改动）。
4. **Deploy**。之后每次 push 到默认分支都会自动重新部署。

### 方式二：Vercel CLI

```bash
npm i -g vercel
vercel          # 首次会引导你关联项目，生成 preview 部署
vercel --prod   # 发布到生产域名
```

`vercel.json` 已包含 SPA 回退规则（所有路径重写到 `/index.html`），所以直接访问子路径或刷新不会 404。构建产物路径固定为 `dist/`，与 `npm run build` 一致。

## 已知限制

- 不写入游戏配置文件，推荐值需要你在游戏设置里手动填写。
- 没有账号系统，历史记录只存在当前浏览器的 `localStorage`。
- 浏览器指针锁定（Pointer Lock）在部分嵌入式 WebView 中不可用，请用桌面版 Chrome / Edge。
- 测的是单次静态点击的甩枪精度，不含跟枪与移动目标；对"甩枪型"玩家的参考价值高于"跟枪型"。

```
src/
├─ App.jsx                  向导状态机（setup → calibrate → result）
├─ components/
│  ├─ SetupScreen.jsx       DPI / 灵敏度输入与换算预览
│  ├─ CalibrationScreen.jsx 轮次推进与候选灵敏度下发
│  ├─ AimCanvas.jsx         全屏测试场地：房间渲染、指针锁定、命中判定、HUD
│  └─ ResultScreen.jsx      推荐值与每轮得分条形图
├─ hooks/
│  ├─ usePointerLock.js     指针锁定封装
│  └─ useCalibration.js     搜索状态机与 React 的桥接
└─ lib/
   ├─ aimModel.js           球面投影、命中判定、目标半径（纯函数）
   ├─ targets.js            六目标场：生成、间距约束、击杀后补位（纯函数）
   ├─ room.js               房间几何、透视投影与近平面裁剪（纯函数）
   ├─ goldenSearch.js       黄金分割搜索状态机（纯函数）
   ├─ scoring.js            单局计分（纯函数）
   ├─ sens.js               DPI / 灵敏度 / eDPI / cm360 换算
   └─ storage.js            localStorage 历史记录
```
